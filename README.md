# Там, де живе світло

Інтерактивна 3D-сцена покинутого будинку за мотивами навчального матеріалу «Мініпроєкт». Реалізована на Three.js, TypeScript і Vite. Один юніт сцени приблизно відповідає одному метру.

## Можливості

- Будинок, дах, прибудова, димар, вікна, сходи, могили, кущі, доріжка й паркан з примітивної геометрії Three.js.
- Локальні WebP-текстури, завантажені через `TextureLoader`, та PBR-матеріали (`MeshStandardMaterial`) з картами кольору, нормалей, шорсткості й затінення.
- Місячне й навколишнє освітлення, ліхтар біля дверей, три анімовані привиди, м’які тіні.
- Небо через аддон `Sky` і експоненційний туман `FogExp2`.
- Налаштування світла, кольорів, туману, неба, швидкості привидів і повторення текстури землі через панель параметрів.
- `OrbitControls` для обертання й масштабування. За налаштування `prefers-reduced-motion` рух привидів і мерехтіння вимкнені.

## Запуск

Потрібен Node.js 20.19+ та npm.

```powershell
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite (зазвичай `http://localhost:5173`). Для перевірки TypeScript і створення `dist/`:

```powershell
npm run build
```

## Публікація на Vercel

Після успішного локального білду встановіть офіційний Vercel CLI і виконайте команди з кореня проєкту:

```powershell
npm install -g vercel
vercel login
vercel --prod
```

Під час налаштування оберіть поточну теку. Vercel розпізнає Vite; build command — `npm run build`, output directory — `dist`. Після деплою CLI виведе публічну URL-адресу. Альтернатива: завантажте проєкт у власний Git-репозиторій та імпортуйте його в [Vercel](https://vercel.com/new) з тими самими параметрами.

## Джерела ресурсів

Використано WebP-текстури з наданої теки `materials`. Набори `castle_brick_broken_06`, `roof_slates_02`, `plastered_stone_wall`, `coast_sand_rocks_02` та `leaves_forest_ground` походять з [Poly Haven](https://polyhaven.com/textures); карти дверей і маски підлоги надані з матеріалом уроку. Робочі копії необхідних текстур лежать у `public/textures/`; вихідна тека `materials/` для запуску не потрібна.

Звуки, завантаження готових 3D-моделей і Basis не входять до цієї версії: вони наведені в умові як додаткові ідеї, а не обов’язкові вимоги.
